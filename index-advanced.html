01 · About

Where field reality
meets data intelligence.

A short story about how I ended up writing code in Bihar's most data-rich, least-digitised spaces — and why that matters.

I'm a public health data professional and full-stack developer currently working as a Gandhi Fellow with Piramal Foundation in Muzaffarpur, Bihar. My day starts in the field — coordinating with ASHA workers, ANMs, PHC/CHC staff, and district officials — and ends with Python scripts, SQL queries, and data pipelines that turn raw field data into decisions.

I work across the entire data lifecycle: from ODK Collect & ODK Central forms in the field, through cleaning and validation in Python, to MIS reports that land on the desks of district officials. Outside of health data, I've built and deployed production MERN stack apps with JWT auth, REST APIs, Nginx, and PM2 — and I use AI tools daily to sharpen both workflows.

My edge is simple: I've actually been in the field, so I know what the data means before it ever hits a spreadsheet. That perspective drives every pipeline, dashboard, and codebase I build.

SpaceX Launch Success Prediction

Capstone project for the IBM Data Science Professional Certificate. Goal: predict whether the Falcon 9 first stage will land successfully, given mission, orbit, payload, and launch-pad data.

  • Data collection: SpaceX REST API + Wikipedia web scraping (BeautifulSoup)
  • Wrangling: One-hot encoding of categorical features, missing-value handling
  • EDA: SQL queries on the cleaned dataset, scatter / bar / line visualisations
  • Modelling: Logistic Regression, SVM, Decision Tree, KNN — picked by F1 score
  • Deployment: Interactive Dash + Plotly dashboard for live launch-data exploration

Stack: Python · Pandas · Scikit-learn · SQLite · Dash · Plotly · Folium.

VHSND Field Data Quality & Insights

Built during my Gandhi Fellowship to handle the messy reality of community health session data flowing in from ODK Collect on the field.

  • Automated validation rules against the official VHSND schema (required fields, valid value ranges, skip-logic violations)
  • Surfaces data-quality gaps with block- and ANM-level breakdowns for program review
  • Outputs a clean, analysis-ready dataset for the MIS pipeline
  • Weekly summary emails to block-level officers

Stack: Python · Pandas · ODK Central API · openpyxl.
